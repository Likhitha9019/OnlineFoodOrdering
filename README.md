# Online Food Ordering Management System

## Project Description

The Online Food Ordering Management System is a Spring Boot application
that allows customers to manage food orders and track their order status.

## Main Modules

- Customer Management
- Food/Menu Management
- Order Management
- Order Items
- Payment Status
- Order Tracking

## Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- PostgreSQL
- REST API
- Maven
- Postman

## Order Status

- Placed
- Preparing
- Out for Delivery
- Delivered

## Project Structure

Controller → Service → Repository → Database

## Database

PostgreSQL

Database Name: onlinefooddb
